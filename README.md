# Sequel Box – Downloads

Official Windows downloads for **Sequel Box**, the video editor.

**Download:** go to [Releases](../../releases/latest) and get `SequelBox-Setup.exe`.

Website: https://sequelbox.com

## Install
1. Download `SequelBox-Setup.exe`
2. Double-click it
3. If Windows shows a blue warning, click **More info** → **Run anyway**
